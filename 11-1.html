Web 前端长度单位

CSS 中的长度单位用于描述尺寸、间距、字号等数值。它们分为 绝对单位与相对单位两大类。相对单位会随浏览器、 父元素或视口变化，是响应式布局的基础。本页用可视化色条展示每个单位的实际效果。

一、绝对单位

固定大小，不随环境变化

px

像素 · 最常用

屏幕上最小的显示单元。网页开发中的默认选择，适合精确控制边框、阴影等细节。

width: 120px;

cm

厘米

物理长度单位。1cm ≈ 37.8px（96dpi 屏幕下），打印样式中更有意义。

width: 2cm;

mm

毫米

1mm ≈ 3.78px。比厘米更细的物理单位，常用于打印排版。

width: 40mm;

in

英寸

1in = 96px = 2.54cm。源自传统印刷行业的长度单位。

width: 1.5in;

pt

磅

1pt = 1/72 英寸 ≈ 1.33px。字体大小的传统单位，Word 等软件中常见。

width: 110pt;

pc

派卡

1pc = 12pt = 16px。印刷排版单位，在网页中极少使用。

width: 8pc; /* = 128px */

二、相对单位

随参照物变化 · 响应式布局的核心

%

百分比

相对父元素同属性的尺寸。宽度用百分比可实现自适应流式布局。

width: 45%; /* 父级宽度的 45% */

em

相对父级字号

相对父元素的 font-size。层层嵌套时会不断放大或缩小，需谨慎使用。

font-size: 1.5em; /* 父级 16px → 24px */
em：跟随父级字号

rem

相对根字号

相对根元素 html 的 font-size。不受父级影响，是现代网页最推荐的相对单位。

font-size: 1.5rem; /* 根级 16px → 24px */
rem：始终跟随根级字号

vw / vh

视口宽 / 高

1vw = 视口宽度的 1%，1vh = 视口高度的 1%。适合做通栏区块与首屏高度。

width: 20vw; /* 视口宽的 20% */

vmin / vmax

视口小边 / 大边

vmin 取宽高中较小者，vmax 取较大者。适合做正方形自适应容器。

width: 25vmin; height: 25vmin;

ch / ex

字符度量单位

ch = 数字 0 的宽度，ex = 小写字母 x 的高度。适合限制每行字符数。

width: 20ch; /* 约 20 个字符宽 */
每行大约放 20 个字符

三、em 与 rem 的区别

同样的 2em / 2rem，结果完全不同

em：逐级继承父级字号

父级 20px 2em = 40px

再嵌套一层 2em 会变成 80px —— 因为它参照的是直接父级。

rem：始终参照根级字号

父级 20px 2rem = 32px

无论父级如何设置，rem 都以 html 的 16px 为基准，结果稳定可控。
