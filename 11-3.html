五、核心知识点

写好 3D 动画需要掌握的四件事

1. 开启透视

在父容器上设置 perspective，子元素的 3D 变换才有近大远小的效果。

.stage { perspective: 900px; }

2. 保留 3D 空间

需要嵌套 3D 元素时，父级必须声明 preserve-3d，否则子元素会被压平。

.cube { transform-style: preserve-3d; }

3. 坐标轴与位移

先旋转再沿 z 轴平移 translateZ，把每个面推到立方体表面。

transform: rotateY(90deg) translateZ(70px);

4. 动画与过渡

持续动画用 @keyframes + animation；交互触发用 transition + :hover。

animation: spin 9s linear infinite;
性能提示：3D 动画优先使用 transform 与 opacity， 它们由 GPU 合成，不会触发布局重排；避免在动画中修改 width、top 等属性。 需要精确控制播放时，可用 animation-play-state: paused 暂停动画。
