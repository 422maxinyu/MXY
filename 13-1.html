字体图标 · Font Awesome

字体图标（icon font）把成百上千个图标做进一个字体文件里， 每个图标对应字体中的一个字符编码。本页通过本地下载的 Font Awesome 6 Free（CSS + woff2/ttf 字体文件）演示它的用法： 写一个 <i class="fa-solid fa-house"> 就能显示图标， 并且可以像文字一样用 font-size、color 控制大小和颜色。

二、三种图标风格

solid 实心 / regular 线框 / brands 品牌

fa-solid

实心图标，免费版数量最多（1300+），页面中最常用的一类。

<i class="fa-solid fa-heart"></i>

fa-regular

线框（描边）图标，视觉更轻。免费版可用数量较少，需要 font-weight: 400。

<i class="fa-regular fa-star"></i>

fa-brands

品牌图标（GitHub、HTML5、Python……），使用单独的 “Font Awesome 6 Brands” 字体。

<i class="fa-brands fa-github"></i>

三、字体图标的特性

图标就是文字，所以能被 CSS 文字属性控制

1. 用 font-size 控制大小

图标随字号缩放，任何尺寸都保持矢量清晰。

font-size: 44px;
16px 24px 34px 46px

2. 用 color 控制颜色

字体图标天然单色，继承文字颜色，适合做主题色切换。

color: var(--coral);

3. 自带动画类

Font Awesome 内置 fa-spin、fa-beat、fa-fade 等动画类，无需自己写 keyframes。

<i class="fa-solid fa-circle-notch fa-spin"></i>

4. 与文字、按钮混排

图标是行内元素，可直接放进按钮、标题、列表中与中文一起排版。

.fake-btn i { font-size: 1em; }
收藏本页

四、实现原理

@font-face 加载字体 + 字符编码显示图标

① 引入本地 CSS（已下载到本目录 cdn 文件夹）

<link rel="stylesheet"
      href="./cdn/fontawesome/css/all.min.css">

② 用类名调用图标

<i class="fa-solid fa-house"></i>
<i class="fa-regular fa-heart"></i>
<i class="fa-brands fa-github"></i>

③ CSS 里真正发生的事

@font-face {
  font-family: "Font Awesome 6 Free";
  src: url("../webfonts/fa-solid-900.woff2")
       format("woff2");
}
.fa-solid { font-family: "Font Awesome 6 Free";
            font-weight: 900; }
.fa-house { --fa: "\f015"; }      /* 图标 = 码位 */
.fa-solid:before { content: var(--fa); }

④ 本地文件结构（无需联网，直接双击打开即可）

网页/
├─ 13-1.html                     ← 本页
└─ cdn/
   └─ fontawesome/
      ├─ css/all.min.css         ← 样式与 @font-face 声明
      └─ webfonts/
         ├─ fa-solid-900.woff2 / .ttf      实心图标字体
         ├─ fa-regular-400.woff2 / .ttf    线框图标字体
         ├─ fa-brands-400.woff2 / .ttf     品牌图标字体
         └─ fa-v4compatibility.woff2 / .ttf 旧版兼容字体
小结：字体图标 = 把图标画进字体文件，用类名选中某个码位的“字符”。 优点是矢量清晰、请求少、能用 font-size / color 随意控制； 局限是一次要加载整个字体文件、只能单色、无法单独修改某个图标的局部线条。 想看另一种方案，请打开 13-2 · SVG 图标（Lucide）。
