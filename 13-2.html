SVG 图标 · Lucide

SVG（可缩放矢量图形）图标是一段写在页面里的 <svg> 代码： 用 path 路径描出图形，浏览器直接渲染成本矢量图。 本页使用本地下载的 lucide.min.js（Lucide 图标库）， 页面中的 <i data-lucide="house"> 会被脚本替换成真正的 <svg> 元素，随后就能用 CSS 控制它的 颜色（stroke）、线宽、大小和动画。

二、SVG 图标的可塑性

它是真正的元素，CSS 属性都能作用上去

1. 用 width / height 控制大小

SVG 自带 viewBox，任意尺寸都等比缩放、绝不模糊。

.icon { width: 36px; height: 36px; }
16 24 36 50

2. 用 color 控制描边颜色

Lucide 图标 stroke="currentColor"，颜色跟随文字的 color 继承。

.star { color: var(--coral); }

3. 用 stroke-width 控制线宽

同一个图标，只改描边粗细就能从“纤细”变成“加粗”。

.thin { stroke-width: 1; }
1 2 3.2

4. 用 transition / transform 做交互

SVG 是普通元素，hover 旋转、缩放、换色，还能放进按钮里。

.chip:hover { transform: rotate(20deg) scale(1.12); }

三、字体图标 vs SVG 图标

13-1 Font Awesome 与本页 Lucide 的对照

对比项 字体图标（13-1 · Font Awesome） SVG 图标（13-2 · Lucide）
实现方式 @font-face 加载字体，:before 输出字符编码 页面中真正的 <svg> 元素，path 描出图形
引入文件 CSS + woff2/ttf 字体文件（本目录约 1MB） 一个 lucide.min.js（约 444KB，含 2100+ 图标）
颜色 color 统一改色，只能单色 stroke 继承 color，不同 path 还能分别上色
尺寸 font-size 缩放 width / height 缩放，viewBox 保证不变形
局部改样式 做不到，整套图标共享字体属性 可单独设置某条路径的线宽、虚线、圆角
加载失败时 整套图标一起消失（文字变豆腐块） 只影响对应图标，其余互不干扰
常见用法 <i class="fa-solid fa-house"> <i data-lucide="house"> + createIcons()

四、实现原理

本地脚本把占位元素替换成 <svg>

① 引入本地脚本并调用 createIcons()

<script src="./cdn/lucide/lucide.min.js"></script>
<script>
  lucide.createIcons();
</script>

② 写占位元素（图标名写在属性里）

<i data-lucide="house"></i>
<i data-lucide="trash-2"></i>

③ 脚本执行后实际生成的 SVG

<svg xmlns="http://www.w3.org/2000/svg"
     width="24" height="24" viewBox="0 0 24 24"
     fill="none" stroke="currentColor"
     stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round"
     class="lucide lucide-house"
     data-lucide="house">
  <path d="M15 21v-8a1 1 0 0 0-1-1h-4a1 1
           0 0 0-1 1v8"/>
  <path d="M3 10a2 2 0 0 1 .709-1.528l7-6a2 2
           0 0 1 2.582 0l7 6A2 2 0 0 1 21 10v9
           a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2z"/>
</svg>

小结：SVG 图标 = 把图形本身交给浏览器绘制。 优点是可多色、可单独改样式、按需加载体积小、缩放不失真； 局限是图标一多 HTML 代码会变长（可用 sprite 雪碧图或脚本批量生成来优化）。 两种方案各有取舍，配合 13-1 字体图标 一起看会更清楚。
