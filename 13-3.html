实现要点

.tab-shell {
  position: fixed;
  left: 0; right: 0; bottom: 0;
  width: 100%;                /* 始终铺满屏幕，不固定宽度 */
  padding-bottom: env(safe-area-inset-bottom);
}
.tabbar { display: flex; }
.tab-item { flex: 1 1 0; }   /* 四项等分，宽度自适应 */

1) 导航用 position: fixed 固定在视口底部，宽度 100% 随屏幕自适应；2) 标签用 flex 四等分；3) 选中态由隐藏的 radio 驱动，纯 CSS 切换，无需 JavaScript；4) 内容区预留 padding-bottom 避让导航，避免末尾内容被遮住。

本页图标全部来自 font/iconfont.css（<i class="iconfont icon-shouye">），角标为图标容器右上角绝对定位的 .badge 与 .dot。
