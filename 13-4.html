实现要点

.tab-shell {
  position: fixed;
  left: 0; right: 0; bottom: 0;
  width: 100%;                /* 始终铺满屏幕，不固定宽度 */
  padding-bottom: env(safe-area-inset-bottom);
}
.tabbar { display: flex; }
.tab-item { flex: 1 1 0; }   /* 四项等分，宽度自适应 */

1) 图标写成 <i data-lucide="house">，由本地 cdn/lucide/lucide.min.js 替换成 <svg>；2) SVG 的 stroke="currentColor" 让选中态只需改 color；3) 选中态用 JS 切换 .is-active 类，四个标签仍是 flex 等分；4) 数字徽章与红点同样绝对定位在图标容器右上角，与字体版位置完全一致。

<script src="./cdn/lucide/lucide.min.js"></script>
<script>
  lucide.createIcons();
  document.querySelectorAll('.tab-item').forEach(function (item) {
    item.addEventListener('click', function () {
      document.querySelectorAll('.tab-item').forEach(function (el) {
        el.classList.remove('is-active');
      });
      item.classList.add('is-active');
    });
  });
</script>
